# learn-codex

> Build a Go mini-version of [openai/codex](https://github.com/openai/codex), session by session — each chapter ends with the upstream Rust source.

[中文 README ↓](#中文)

## What this is

`openai/codex` is a Rust monorepo with 120+ crates: a TUI, app-server transport, OS sandboxing, MCP integration, V4A patch DSL, execpolicy DSL, rollout persistence — it can be intimidating. **This repo isn't a fork or a port.** It's a *teaching companion*: 10 small Go modules, each adding one mechanism on top of the previous, plus an end-to-end integration chapter and two appendices. Read in order, build along, and after a weekend you'll know the *why* behind every load-bearing decision in upstream `codex-rs/`.

The pedagogy is borrowed from [shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code): each chapter is six sections — Problem · Solution · How It Works · What Changed · Try It · Upstream Source Reading. Bilingual (中文 + English). Mobile-friendly ASCII diagrams.

# learn-codex (中文)

> 用 Go 从零渐进构建 [openai/codex](https://github.com/openai/codex) 的核心 10 个机制，每节末尾对照上游 Rust 源码。

## 这是什么

`openai/codex` 上游是一个 120+ crate 的 Rust 单体仓库：TUI、app-server 传输、OS 沙盒、MCP 集成、V4A patch DSL、execpolicy DSL、rollout 持久化——直接读会被劝退。**本仓库不是 fork 也不是移植**，而是一份**教学伴侣**：10 个小型 Go 模块，每节在上一节的基础上加一个机制，外加一节端到端集成和两个附录。按顺序跟着写一遍，一个周末就能搞清上游 `codex-rs/` 每个核心决策背后的"为什么"。

教学法仿照 [shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)：每节六段——Problem · Solution · How It Works · What Changed · Try It · Upstream Source Reading（上游源码阅读）。双语（中文 + English）。手机能看清的 ASCII 图。
